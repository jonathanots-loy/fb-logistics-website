PHOTOS — FB Logistics
=================================

Tous les emplacements ci-dessous sont actuellement remplis avec des photos Unsplash/Pexels
(dossier source : C:\Users\jonat\OneDrive\Bureau\photo logistiques), redimensionnées
et compressées pour le web. Ce sont des photos de remplacement réalistes, pas les
vraies photos de l'entreprise — à remplacer dès que de vraies photos (équipe, bureaux,
partenaires) seront disponibles. Ces photos de conteneurs/camions restent cohérentes
avec le métier (sourcing/import-export/logistique) même si FB Logistics n'est pas transporteur.

Chaque page a volontairement une composition différente (gros plan / plan large /
vue aérienne / intérieur) pour éviter que le site se répète visuellement d'une page
à l'autre.

Pour remplacer une photo : dépose le nouveau fichier dans /images/ avec EXACTEMENT
le même nom que ci-dessous (il écrase l'ancien). Rien d'autre à toucher dans le code.
Si le fichier est absent, le site retombe automatiquement sur un emplacement "à
compléter" stylé.

Formats : .jpg recommandé. Compresser les photos avant de les déposer (viser
~150-400 Ko pour une couverture, ~50 Ko pour une vignette) pour ne pas alourdir le site.
